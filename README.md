# Secure Vault Frontend

## Overview

React Single Page Application for Secure Vault.

## Technologies

- React
- Material UI
- Axios
- Docker
- Nginx

## Running Locally

1. Clone the repository.
2. Configure the required environment variables.
3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

## Docker

The included Dockerfile is intended to be used by the deployment repository.
Refer to the **Secure Vault Deployment** repository for containerized deployment.

See `.env.example`.
